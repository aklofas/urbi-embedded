# api-manifest-symbol-allowlist.txt — ratchet for unprefixed exports.
#
# Every entry is an exported [TDRBWVCu] symbol in liburbi.a that sits
# outside the urbi_/URBI_ namespace (STYLE.md). -fvisibility=hidden
# protects shared-object embedders, but a static-archive link sees all
# of them, so each one is a potential duplicate-symbol collision in an
# embedder's build.
#
# This file freezes today's inventory: check-api-manifest.sh fails on
# any NEW unprefixed global. It grows only when a re-foundation task
# adds a genuinely new cross-TU name in the runtime core or the standard
# library, and shrinks whenever one is made static or renamed; it is
# deleted once every remaining name is prefixed or internal. A name that
# does not begin with u is never acceptable here.
