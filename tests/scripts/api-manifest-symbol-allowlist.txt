# api-manifest-symbol-allowlist.txt — the ratchet for unprefixed exports.
#
# Every entry is an exported [TDRBWVCu] symbol in liburbi.a that sits
# outside the urbi_/URBI_ namespace (STYLE.md).  -fvisibility=hidden
# protects shared-object embedders, but a static-archive link sees all of
# them, so each one is a potential duplicate-symbol collision in an
# embedder's build.
#
# This file freezes today's inventory: check-api-manifest.sh fails on any
# NEW unprefixed global.  It grows only for a genuinely new cross-TU name
# and shrinks whenever one is made static or renamed; it is deleted once
# every remaining name is prefixed or internal.  A name that does not
# begin with u is never acceptable here.
#
# Regenerated at the core re-foundation, against the archive the
# re-founded tree produces.  Everything the old runtime exported is gone
# with it; what is left is the compiler frontend (ulex_/uparse_/uemit_/
# uchunk_/uarena_/uvarint_), the runtime core (ugc_/uobj_/ustr_/ustrand_/
# usched_/uexec_/uwatch_/urealm_/uboot_/utag_), and the standard library's
# install tables.  Regenerate with:
#
#   nm build/host/liburbi.a | grep -E ' [TDRBWVCu] ' | awk '{print $NF}' \
#     | grep -vE '^(urbi|URBI)_' | sort -u
